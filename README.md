# Hope — Autism Family Support Platform

A calm, multilingual Progressive Web App (PWA) that supports parents of autistic children.

## What Hope does

- 🆘 **Help Now** — Step-by-step guidance during crisis moments
- 📚 **Resource Hub** — Bite-sized guides in English and French
- 👩‍⚕️ **Specialist Directory** — Find verified, affordable specialists

## Built for

Underserved communities first — Global South families who have no platform built for them.

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- next-intl (English, French, Dari)
- @serwist/next (Offline support)
- Zustand
- Framer Motion

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.
